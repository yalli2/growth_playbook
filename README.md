# 그로스 컴파운드 (Growth Compound)

> 작은 실험이 복리로 쌓이는 성장팀 만들기 — HR 성인 학습 프로그램

Andy Boyd의 『The Enterprise Growth Playbook』을 바탕으로 만든 **9개 챕터** 인터랙티브 사이트입니다. 챕터마다 배우기 → 실습하기 → 함께 보기 → 확인하기로 진행하며, 참가자 모두의 결과가 레이더·히트맵·퍼널·우선순위 그리드·칸반·ICE 버블 등으로 실시간 모입니다.

| 장 | 챕터 | 실습 |
|---|---|---|
| 1 | 성장팀의 일 | 역할 코인 배분, 성장 vs 리포팅 분류, KPI 벽 |
| 2 | 시스템 전체를 보라 | 복리 시뮬레이터, 매일 1% 계산기, 구간 책임 히트맵 |
| 3 | 성장 문화 만들기 | 문화 진단 레이더, 좋은 실패 판정, 결정 vs 수집 |
| 4 | 선결 조건: PMF와 성장 도구 | Ellis 40% 게이지, AARRR 지표, A/B 실험실 |
| 5 | 그로스 프로세스: Sprint 0 | 퍼널 히스토그램, 아이디어 백로그, 우선순위 그리드 |
| 6 | 그로스 잼 | 실시간 익명 브레인스토밍·투표·반대 의견·실행 계획 |
| 7 | 애자일로 계속 움직이기 | 공용 실험 칸반(WIP·충돌 경고), 스탠드업, 배움 아카이브 |
| 8 | 실험 관리 도구와 성장 회의 | ICE 점수·박수·지명, 북극성 트리, KPI 대시보드 |
| 9 | 나의 그로스 플레이북 | 준비도 레이더, 90일 로드맵, 첫 실험 서약, 플레이북 한 장 |

## 게시 (GitHub Pages)
Settings → Pages → Branch: `main` / root. 주소: `https://yalli2.github.io/growth_playbook/`

## 실시간 공유 켜기 (Firebase, 무료)
기본은 **단독 모드**(이 브라우저에만 저장, 샘플 참가자 12명 표시)입니다. 여러 사람이 함께 보려면:
1. Firebase 콘솔에서 프로젝트 → **Realtime Database** 생성
2. Rules에 붙여 넣기
```json
{ "rules": { "growth-compound": { "$room": { ".read": true, ".write": true } } } }
```
3. 데이터베이스 주소를 `config.js`의 `firebaseUrl`에 입력 후 커밋
4. 수업마다 `?room=HR2026` 처럼 방 코드를 달리하면 반별로 분리됩니다.

개인정보·회사 기밀은 입력하지 않도록 안내해 주세요.
